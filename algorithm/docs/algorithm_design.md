# 算法设计

## 目标与边界

算法估计腕屈伸与桡尺偏，输出姿势暴露、确定性工效提醒、可选已标定压力/安全症状停止提示以及 A/B/C 参与者内比较。它不诊断疾病，不预测发病概率，不把 RFP-602 原始值解释为压力，也不把外部装置力矩解释为肌腱力。

没有独立拇指传感器时，不输出拇指角或拇指负荷结论。

```mermaid

    K[独立 CAL 与静态验证] --> D
```

## 目标安装与相对姿态

目标硬件为两个六轴 IMU：

- `forearm`：腕关节线向肘部约 `5 cm`、允许 `4–6 cm` 的前臂背侧中线。
- `hand`：距腕关节线约 `2–3 cm` 的手背第 3 掌骨中段。
- 两节点同侧，轴向一致，坐标系声明为 `sensor_local`。

内部四元数为 `[w, x, y, z]`。腕相对姿态：

```text
q_rel = inverse(q_forearm) × q_hand
```

默认融合为六轴 Madgwick，`beta=0.08`。Mahony 对照参数为 `kp=0.5`、`ki=0`。只有完成硬铁、软铁和现场磁环境标定后，才适合启用九轴；当前默认关闭磁力计。

## 时间与同步

原始双 IMU 支持 `timestamp_ms` 或 `device_ms`。设备时间会按文件首点归一为相对时间。同步同时检查：

- 首点偏移。
- 末点偏移。
- `forearm → hand` 最近邻误差。
- `hand → forearm` 最近邻误差。
- 双向 `p95` 和 `max`。

任一门限超过 `20 ms`，同步门控失败并将角度质量归零。`host_unix_ms` 不参与运动学。

## 独立 CAL

现场 A/B/C 的任务文件与 CAL 文件分离。CAL 必需区间为：

```text
neutral
flexion
extension
ulnar_deviation
```

`radial_deviation` 为可选兼容区间。任务文件不要求中立前导段，也不重新估计中立位或功能轴。

CAL 处理步骤：

1. 双节点同步和共同静止质量筛选。
2. 使用开始约 `0.5 s` 的有效加速度中值初始化 roll/pitch，初始 yaw 固定为零。
3. 估计两节点陀螺零偏。
4. 计算中立相对四元数。
5. 将相对旋转转换为旋转向量并估计 FE/RUD 功能轴。
6. 构造第三正交轴并保存完整校准档案。

任务应用步骤：

1. 对任务两路 IMU 使用相同的加速度倾角初始化。
2. 计算任务 `q_rel`。
3. 使用存储的中立四元数归零。
4. 使用存储的功能轴投影，不重新定轴。

默认公开数据和旧的嵌入式校准路径仍使用单位四元数初始化，以避免改变历史模型输入分布。加速度初始化严格限定在独立 CAL 工作流。

六轴加速度不能观测绕重力方向的航向。独立文件方案因此依赖安装不移动、轴向不变和启动姿态可重复；它不能证明目标硬件已经满足角度精度要求。

## 功能轴与符号

- FE 正方向为背伸，负方向为掌屈。
- RUD 正方向为尺偏，负方向为桡偏。
- 屈曲与背伸同时存在时，用去均值样本的 SVD/PCA 提取 FE 轴并由标签定向。
- 尺偏与桡偏同时存在时，用双方向样本提取 RUD 轴并由标签定向。
- 只有尺偏时，使用尺偏静态姿态相对中立位的旋转向量确定 RUD 正向。
- 第二功能轴对第一轴做 Gram-Schmidt 正交化，第三轴由叉积得到。
- 非中立功能区间超过 `15 s`、变化不足或两轴近共线时明确失败。

## 质量门控

质量评分结合非有限值、时间异常、加速度模长、饱和、静默、缺口和可选磁场范围。共同中立位门限为：

```text
加速度模长偏差 <= 1.5 m/s²
陀螺模长 <= 0.15 rad/s
共同静止样本 >= 30
共同静止比例 >= 70%
```

`quality < 0.2` 的样本不参与角度状态机；会话有效角度样本率必须 `>=80%`。安全症状和已标定压力是独立通道，即使角度质量无效也能触发停止提示。

## 角度暴露与提醒

角度工程分层：

- 屈伸绝对值 `<15°` 为绿，`15–30°` 为黄，`>30°` 为红。
- 桡尺偏绝对值 `<10°` 为绿，`10–20°` 为黄，`>20°` 为红。
- 背伸 `>=15°` 且尺偏 `>=10°` 为复合红区。

提醒规则：

- 连续角度红区达到 `10 s` 才形成角度事件。
- 同类角度提醒冷却为 `300 s`。
- A/B 只将事件记为 `would_alert=true`，实际 `alert=false`。
- C 将同一确定性事件输出为实际提醒。
- 安全停止不受 A/B 的提醒开关和角度冷却影响。

## RFP-602、压力与安全症状

目标硬件只有一个 RFP-602，位于护腕内层、腕关节线向肘部约 `1–2 cm` 的腕背中央。未完成载荷、迟滞、蠕变和有效接触面积标定前：

```text
fsr_raw_adc / fsr_raw / fsr_normalized_pct
```

只作为接触载荷代理量，输出 `mean/p95/max`，不进入压力状态机，不生成 kPa、`pressure_zone` 或压力 Go/No-Go 结论。

旧的 `p_radial_kPa / p_dorsal_kPa / p_ulnar_kPa` 仅作为已经标定为 kPa 的兼容通道保留。只有这些通道适用 `<3.0 / 3.0–4.4 / >4.4 kPa` 的工程筛查。

安全字段分工：

- `discomfort_nrs`：`0–10` 主观评分，只记录。
- `safety_symptom_flag`：`0/1` 独立停止通道。
- `discomfort`：旧版 `0/1` 兼容停止通道。

已标定压力红区或安全症状触发时，原因统一为：

```text
release_and_stop_calibrated_pressure_or_safety_symptom
```

输出是软件提示，不是执行器控制。

## A/B/C 试验条件

| 条件 | 支撑档 | 提醒 | 解释 |
| --- | ---: | --- | --- |
| A | 0 | 关 | 无支撑基线，保留静默 `would_alert` |
| B | 1 | 关 | 测量支撑增量，保留静默 `would_alert` |
| C | 1 | 开 | 在与 B 相同支撑下测量提醒增量 |

顺序固定为 `A → B → C`。C 收到提醒后只回到舒适中立位。所有 A/B/C 条件都禁用旧的“继续收紧”建议。

比较语义：

```text
A vs B = support_increment
B vs C = reminder_increment_at_same_support
A vs C = support_plus_reminder_combined
```

## 指标与三态判定

```text
P_high = 高角度暴露时间 / 有效任务时间 × 100%
D_FE = integral(max(abs(theta_FE) - 15, 0) dt)
D_RUD = integral(max(abs(theta_RUD) - 10, 0) dt)
D_total = D_FE + D_RUD
tau_assist = cable_tension_N × lever_arm_m
```

`L_max` 为最长连续高角度暴露。Go/No-Go 采用：

```text
NO-GO         任一可评估检查失败
NOT-EVALUABLE 没有失败，但至少一项缺少证据
GO            所有检查均有证据且通过
```

只有未标定 FSR 而没有 kPa 压力时，`pressure_screening_pass=null`，整体不能判 GO。舒适度暂定工程通过线为 `>=5/7`，不是临床阈值。

## CNN-HMM 影子层

监督任务只识别：

```text
background
extension
flexion
radial_deviation
ulnar_deviation
```

输入以 `50 Hz` 重采样，窗口 `1.5 s`、步长 `0.5 s`，特征为 FE/RUD、其导数、角速度和质量。模型为单层时域卷积、ReLU、全局平均池化和 Softmax，随后由不利用固定动作顺序的 HMM/Viterbi 平滑。

推理时窗口平均质量低于 `0.5`、缺失比例超过 `0.1` 或校准后置信度低于 `0.55`，输出 `unknown`。当前 11 折 HMM macro-F1 均值约 `0.559`，拒识覆盖率约 `50.61%`，只能保持 `shadow`。

## 多数据集专家层

统一数据集注册表保存来源、许可、必需模态、标签映射、允许用途和证据限制。每个窗口携带 `dataset_id`；联合构建时对参与者、会话和序列 ID 加来源命名空间，防止 ID 碰撞与数据泄漏。

当前任务专家划分为：

- `wrist_motion_activity`：现有 Upper-body 五分类 CNN-HMM。
- `wrist_angle_reference` 与 `upper_limb_angle_context`：Optotrak 和未来 ULTRA-MoCap 角度/坐标专家。
- `industrial_work_context`：未来 OpenPack、LARa 工作场景专家。
- `adl_context`：未来 MyoKi 日常活动专家。
- `target_domain_quality`：无标签 SheWrist 实采的域质量审计，不是监督分类器。

异构专家只在输出标签交集上融合；Optotrak/ULTRA 一类连续角度参考进入独立误差与坐标验证，不与活动类别概率直接平均。融合权重必须由目标硬件带标签验证集确定，并记录验证集 ID 与指标；未安装数据、缺少模态或无验证权重时显式拒绝。当前融合配置为禁用，不存在默认平均权重。任何专家和融合输出仍只生成影子 Token，不改变确定性状态机。

```text
确定性角度/已标定压力/安全症状状态机 -> 提醒和停止语义
CNN-HMM/未来任务专家                       -> 动作、上下文、置信度和 Token
证据门控融合                              -> 仅在目标验证权重存在时启用，控制权限 none
本地模板或未来外部解释器                  -> 非临床文字，控制权限 none
```

## 可解释限制

- 旋转向量沿功能轴投影是工程近似，极大角度和复合姿势会出现耦合。
- 六轴融合不能长期校正绕重力轴漂移。
- 独立 CAL 与任务分文件依赖安装不变和可重复启动姿态。
- 皮肤软组织伪影、绑带滑移、重戴误差和跨轴串扰尚需目标硬件真值验证。
- 未标定 RFP-602 不是压力、肌腱力或腱鞘内压力。
- 所有角度、持续时间、舒适度和压力边界都是首版工程参数，不是疾病阈值。
